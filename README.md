# offstore

The coming-soon page for **offstore.in**.

Small, clean apps, made our way. More soon.

## What's here

- `index.html`: the whole site. One file with its CSS inline and nothing to build. The only outside request is the Space Grotesk font from Google Fonts.

It follows the system's light/dark setting and works at any width, from phones up.

## Run it locally

Open `index.html` in a browser.
